# Portfolio deportivo de Ramón Curbalán

Nueva base integral procedente de ramon_sport_portfolio.zip. Web estática autocontenida: index.html incluye estilos y gráficos CSS, sin dependencias ni assets externos.

Publicado en https://raymonchu48.github.io/Deportivo/ con GitHub Pages desde main, carpeta raíz. .nojekyll evita procesamiento Jekyll.

Validación: 1440, 1024, 768, 390 y 320 px; navegación por anclas, contacto por email y vuelta al inicio. Ajustes de portada, navegación móvil, foco visible y movimiento reducido.

La implementación y los recursos anteriores se han retirado del árbol publicado; permanecen recuperables en el historial Git.
